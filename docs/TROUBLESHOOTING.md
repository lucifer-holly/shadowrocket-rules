# 故障排查与技术限制

## 验收顺序

1. 仅开 base：Safari 常用网页、App 登录/消息、支付、国内与海外访问、SSH 逐个验证。
2. 单独增加目标 App 模块，再验证开屏和该 App 的关键操作。每次只加一个。
3. 最后增加响应过滤器；确认模块引用自己仓库的脚本，下载成功，相关主机已启用解密。
4. 在手机“数据/请求记录”和 HTTPS 解密日志查看命中的规则。避免导出或分享完整请求头和响应。

仓库不包含任何你的登录 Cookie、Authorization、设备标识或业务抓包。为了定位误杀只需要脱敏的主机名、路径、时间、App 版本及启用模块；分享前删去查询参数值和账号/订单信息。

## 常见现象

| 现象 | 检查与处理 |
|---|---|
| 日志里每条都是 `ROUTING,PROXY`，广告一条没拦 | 首页「全局路由」不是「配置」。选「代理」时所有流量直接送去节点，主配置和模块的 `[Rule]` 都不执行，去广告①②的域名拦截全部失效，国内 App 也绕到海外节点。改回「配置」；正常时日志显示具体命中的规则，例如 `DOMAIN-SUFFIX,weibo.cn,DIRECT` |
| 开屏还在 | 确认配置模式、模块启用、证书信任、主机覆盖和规则命中；已有广告缓存可能仍会显示。先冷启动、等待过期；不要首先清空所有 App 数据 |
| 开屏去掉了，隔一两天又回来（闲鱼等阿里系 App） | App 拿到调度服务给的服务器列表后改为直接连 IP，按域名的解密和重写就失效了。日志里会看到明文的 `/amdc/mobileDispatch` 和一串 `IP:443`。按 [设备日志](DEVICE_LOGS.md) 的判断表加 `connection_rules`；已加过仍直连 IP，就在 App 里清缓存或重装，清掉旧的服务器列表 |
| 拦截都生效了，开屏还是每次换着出现（例如微博的「摇一摇」开屏） | 日志里开屏相关的地址全被拦，广告 SDK 却仍在上报展示、下载广告图：是 App 里已经缓存的一批广告，拦截挡不住。删除 App 再装（选「删除 App」；「卸载 App」会保留 App 的数据），装好后先连上 Shadowrocket（配置模式）再打开 App。断开 Shadowrocket 或切到「代理」时打开这个 App，它会再缓存一批 |
| 断开 Shadowrocket 后 App 照样异常 | 不是规则造成的：断开后流量不经过 Shadowrocket，证书也不起作用。按 App 自身问题处理：检查 App 更新，清缓存，退出后重新登录；仍不行就重装，或用网页版登录同一账号，判断是 App 还是账号的问题 |
| App 无法联网或登录 | 关闭该 App 模块及脚本，查看 TLS 错误。证书锁定无法通过扩大 MITM 解决 |
| base 开启才异常 | 用 explain 查询目标域名，在 allowlist 加精确例外再重建；无需把整站强制直连 |
| 只有某个接口异常 | 比较关闭对应 App 模块后是否恢复；空字典/空响应并非每个客户端都接受，移除路径比返回假成功更可靠 |
| VPN 频繁断开 | 先换 lite，减少模块，检查客户端日志；未进行本项目的 iOS 内存基准测试 |
| 脚本不生效 | 设备日志看不出脚本有没有运行。先确认脚本已下载：配置 → 点当前配置文件 → 编辑配置 → 脚本 URL，✅ 是下载成功，❎ 是失败；回上一层点「使用配置」会重新下载全部脚本。微博脚本可以自检：Safari 打开 `https://api.weibo.cn/2/profile/me?personal_filter_selftest=1`，显示 `"personal_filter":"weibo"` 和版本日期就是在运行，显示 `校验参数不存在` 就是没运行。再检查实际 URL 是否匹配、是否 JSON、是否能解密、是否超过大小上限；未知 schema 原样返回 |
| 上游链接 404 | 已发布的本地快照继续工作；检查 Actions 报告，人工决定迁移来源，别让失败下载覆盖旧版 |
| GitHub 有新提交但手机没变化 | 手动更新模块/配置/规则集，重连；配置更新与节点订阅更新是不同入口 |
| 同时开多套模块行为不稳定 | 暂停重叠模块，保留 base + 一个 App 模块定位；模块顺序与旧 URL Rewrite/Script 仍可能冲突 |
| 微博某个页面打不开、变空白或内容少了一块 | 先在「模块」页关掉「去广告⑤ 微博完整版」，从后台划掉微博再打开。恢复了就是这个模块的问题：按 [设备日志](DEVICE_LOGS.md) 抓一份日志，记下是哪个页面，对照 `data/weibo.json` 找到对应接口再改 `scripts/weibo.js` |
| App 某个页面空白、消息显示未连接 | 多半是通用域名库拦了该 App 自己的功能域名。在 Shadowrocket「数据」开启日志，复现后找被拒绝（REJECT）的请求，把主机名加入 `data/allowlist.json` |
| App 反复请求“打开通知” | 系统弹窗（「XX 想给你发送通知」）由 iOS 在本机弹出，不经过网络，规则无法拦截。办法：在 iOS 设置 → 通知 → 该 App 里**允许通知，但关掉锁定屏幕、通知中心、横幅和声音**，App 认为已授权就不再提示；也可以加入定时推送摘要。App 自己画的“开启推送”引导弹窗，部分来自网络接口，可抓到接口后按路径拦截 |

离线查询只分析公开规则，不发送请求：

```sh
python3 tools/explain.py doubleclick.net
python3 tools/explain.py 'https://api.m.jd.com/client.action?functionId=xview2Config'
```

## 无法保证去除的广告

- **证书锁定（Certificate Pinning，证书绑定）**：App 不接受个人 CA 时无法读取 HTTPS 路径与响应；仍可拦广告专用域名，但不能整域拦截混合业务 API。
- **HTTP/3（Hypertext Transfer Protocol version 3，超文本传输协议第 3 版）/QUIC**：实际能否解密取决于客户端及应用行为。必要时仅针对目标应用测试是否可回退 TCP；本项目不全局禁止 UDP/443，避免影响 DMIT 或其他应用。
- **自有解析/直连 IP**：域名规则可能失去可见性；本项目不盲目封禁公共 DNS、HTTPDNS 或共享 CDN IP。
- **虎牙直播**：多数接口（`cdnws.api.huya.com`、`wsapi.huya.com`）是私有二进制格式，广告和内容从同一个接口返回，只能拦单独的广告素材地址和第三方广告 SDK；fmz200 也把它列为不能完全去广告的 App。
- **Protobuf / gRPC / 加密响应**：当前原创脚本只处理 JSON，不把二进制响应强行按字符串修改。
- **服务端插入视频广告（SSAI，Server-Side Ad Insertion，服务端广告插入）**：与视频共用媒体流时，网络规则难以稳定区分；可能需要播放器端支持。YouTube/抖音等不承诺全面去除。
- **本地素材、创作者植入、App 自营推荐**：没有独立可拦截网络请求，或与正常内容难以区分。
- **X（Twitter）推广帖与「为你推荐」**：推广帖和推荐内容与正常推文走同一个接口，域名规则只能拦它的广告和追踪域名（已包含在 app-ads 里）。目前没有找到能在 Shadowrocket 上可靠去除推广帖的公开方案。实用办法：首页切到「正在关注」，对不想看的内容点「不感兴趣」或静音。
- **银行 App 的开屏广告**：多数由银行自己的服务器下发。本项目不解密银行和支付主机（防止碰到登录、转账，也避开证书锁定），只拦第三方广告域名、日志里确认只放广告的银行主机（例如建行的 `imageadv.ccb.com`、`adv.ccb.com`），以及少数审核过、只放图片的银行静态主机上的开屏图片（`data/policy.json` 的 `mitm_exceptions`）。广告和业务走同一台银行主机的（例如中信），去不掉。
- **Telegram 频道赞助消息**：通过 Telegram 自己的加密协议（MTProto）下发，网络规则看不到也拦不了；拦它会连带断掉 Telegram。只有 Telegram Premium 能关掉。
- **微信朋友圈广告**：广告卡片的文字和「广告」标签跟普通朋友圈一起，由微信自己的加密协议下发，走的是收发消息的那组服务器，规则解不开也不能拦，拦了会连带断掉消息。去广告①只挡掉广告的图片和视频（`wxs.qq.com`），所以卡片只剩文字和空白；单条广告只能在微信里点「广告」→ 不感兴趣。公众号文章的广告在 iOS 微信 8.0.40 起也经微信自己的通道下发，代理看不到；改文章页隐藏广告位的模块（去广告⑥）试过，主人实测效果不明显，已于 2026-10-23 废弃（见 [微信分析](WECHAT.md)）。
- **YouTube**：`youtube` 模块解密 YouTube 接口并删除广告条目，属于实验功能；YouTube 更改数据格式后可能失效，届时可能弹出「脚本需要更新」的本地通知。
- **Safari 页面残留占位与同源广告**：网络过滤不能隐藏网页元素。页面元素隐藏应使用 Safari 内容拦截扩展（Content Blocker）；此项目不提供“把 EasyList 的 CSS 规则当 Shadowrocket 域名规则”的转换。

平台升级也会改变接口、证书和数据结构。这里给出可维护的规则工程与退路，不把离线通过包装成所有 App 广告已消失。
